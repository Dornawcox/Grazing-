farmOS Server Setup Guide

Step 1 — Enable modules
In farmOS go to Admin → Extend and ensure these are enabled:
• farmOS API (farm_api)
• Simple OAuth (simple_oauth)
• Simple OAuth Password Grant — only needed for password grant

Step 2 — Configure the Consumer
Go to your farmOS /admin/content/consumer and edit the farm consumer.
Set these fields:
• Grant types: check Authorization Code (and/or Password Credentials)
• Redirect URIs: add the exact URL of this page
• Allowed Origins: add this page's origin for CORS

Step 3 — Connect
Use Authorization Code (recommended) — redirects to farmOS to log in.
Or use Password Grant if the Password Grant module is installed.
